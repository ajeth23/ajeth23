## About

I'm **Alan Jethro**, a software engineer and researcher building across **mobile, web, artificial intelligence, and cloud systems**.

My work focuses on creating software that is technically robust underneath while remaining **simple, maintainable, and intuitive** for the people using it.

I work across the full engineering lifecycle — from application architecture and interface development to backend infrastructure, AI experimentation, deployment, and long-term system design.

I'm currently pursuing an **MS in Computer Engineering at Mapúa University** while developing **Vault HQ**, an independent technology initiative exploring intelligent software, agricultural AI, and cloud-native systems.

My personal work, experiments, and engineering projects live at **[ajse.dev](https://ajse.dev)**.
